# Job Alert Service

A Python automation project that checks selected company job boards for Analyst roles, filters results by keyword, tracks previously identified jobs, and sends email updates.

## Features
- Retrieves job listings from public Greenhouse job boards
- Filters roles by keyword
- Tracks previously identified jobs to avoid duplicate alerts
- Sends automated email notifications
- Runs on a schedule using GitHub Actions

## Technologies
Python | Requests | JSON | SMTP | GitHub Actions

## Development
Built, tested, and debugged using AI-assisted programming and manual testing.
